# Al-Shifa Specialized Hospital

JavaFX desktop application for booking and viewing hospital appointments.

## Features
- Book an appointment with an available doctor
- Display and manage appointments
- Object-oriented model: Person, Employee, Doctor, Nurse, Patient, MedicalRecord, Appointment
- Custom exception for unavailable doctors
- File-based storage (`appointments.txt`, `doctors.txt`)

## Tech
Java, JavaFX (FXML), Maven

## Run
```
mvn clean javafx:run
```
